# 🧭 30‑Day AI Learning Plan (with GitHub Strategy)
A structured roadmap using the five GitHub repos I cloned:
- **AI Agents for Beginners**
- **Claude Cookbooks**
- **OpenClaw**
- **AnythingLLM**
- **Unsloth**

This plan builds skills progressively: agents → workflows → RAG → local models → fine‑tuning → full automation.  
It also includes a **GitHub visibility strategy**, so each week produces meaningful commits and uploads.

I will show work on GitHub in **three layers**:

### **Layer 1 — Learning Artifacts (Week 1–2)**
Small notebooks, notes, and simple agents.

### **Layer 2 — Mini‑Projects (Week 2–3)**
OpenClaw workflows, RAG pipelines, AnythingLLM assistants.

### **Layer 3 — Flagship Project (Week 4)**
A full agent pipeline combining:
- Claude Cookbooks reasoning  
- AnythingLLM retrieval  
- OpenClaw execution  
- Unsloth local model inference  

Each week includes **commit/upload milestones**.
